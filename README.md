## Repository Context

This is **not an original DoubleCore project**. The engineering skills, methodology, and upstream implementation are created and maintained by Matt Pocock and contributors.

I keep this fork as a working reference for studying how experienced engineers turn software-engineering practices into **small, composable instructions for coding agents**.

## What I Am Studying

- requirement clarification before implementation;
- domain language and project context;
- test-driven development and feedback loops;
- systematic diagnosis instead of trial-and-error debugging;
- architecture review and incremental codebase improvement;
- turning repeatable engineering behavior into reusable agent skills.
